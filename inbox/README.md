# Папка для новых фотографий

Загрузите сюда JPG или PNG (можно с телефона через github.com → «Add file» → «Upload files»)
и нажмите «Commit changes» в ветку `main`.

GitHub Actions сам:
1. присвоит фото следующий номер (`photo-002`, `photo-003`, …);
2. уменьшит его для быстрой загрузки и удалит метаданные (GPS и т. п.);
3. создаст страницу и QR-коды в `qr-codes/` (PNG и PDF A4);
4. опубликует сайт и проверит, что ссылки открываются.

Исходный файл убирается из `inbox/` после обработки; уже опубликованные фото
и QR-коды не перезаписываются.
